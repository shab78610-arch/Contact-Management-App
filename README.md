# Contact Management Application

## Overview
This is a basic Contact Management Application developed using Python Flask, SQLite, HTML, CSS, and Bootstrap. It allows users to create, view, update, and delete contact records.A simple yet powerful Contact Management Application built with Python and Flask, featuring full CRUD (Create, Read, Update, Delete) operations.

## Features
- Add new contacts
- View all contacts
- Edit existing contacts
- Delete contacts
- Email validation
- Duplicate prevention for email and phone number
- Persistent storage using SQLite

## Technology Stack
- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML
- CSS
- Bootstrap

## How to Run the Application

1. Clone or download the project
2. Open terminal in project folder
3. Create and activate virtual environment

## 🚀 Features

- ✅ **Create** - Add new contacts with first name, last name, and address
- 📖 **Read** - View all contacts in a clean, organized table
- ✏️ **Update** - Edit existing contact information
- 🗑️ **Delete** - Remove contacts you no longer need
- 🎨 **Responsive Design** - Clean UI with CSS styling
- 💾 **SQLite Database** - Lightweight, file-based database
- 🔍 **Search/Filter** - Easily find contacts

## 🛠️ Technology Stack

- **Backend**: Python 3.x, Flask
- **Database**: SQLite (SQLAlchemy ORM)
- **Frontend**: HTML5, CSS3, Bootstrap
- **Template Engine**: Jinja2
