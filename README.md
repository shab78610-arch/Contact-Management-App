# Contact Management Application

## Overview
This is a basic Contact Management Application developed using Python Flask, SQLite, HTML, CSS, and Bootstrap. It allows users to create, view, update, and delete contact records.

## Features
- Add new contacts
- View all contacts
- Edit existing contacts
- Delete contacts
- Email validation
- Duplicate prevention for email and phone number
- Persistent storage using SQLite

## Technology Stack
- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML
- CSS
- Bootstrap
